# MyAgentApp

A no-code AI agent builder platform for non-technical users.

## Project Structure

```
MyAgentApp/
├── frontend/   # Next.js web app
└── backend/    # Python FastAPI + Claude AI
```

## Getting Started

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
